# Vice City Platinum — GTA 6 trophy guide & tracker

![bounty](https://make.fun/badge/gta6-trophy-guide-01.svg)
![rank](https://make.fun/badge/gta6-trophy-guide-01/musengbob/gta6-trophy-guide-01/rank.svg)
![reward](https://make.fun/badge/gta6-trophy-guide-01/musengbob/gta6-trophy-guide-01/reward.svg)

An offline guide and tracker for all 55 PlayStation 5 trophies of Grand Theft Auto VI — checklist with saved progress, export/import, filters, a spoiler setting, a roadmap to the platinum, missable flags, and a cited guide for every trophy, all in its own words. Built for the [make.fun bounty gta6-trophy-guide-01](https://make.fun/bounty/gta6-trophy-guide-01).

## How to run

Serve `app/` with any static server (e.g. `node serve.ts`, then open http://localhost:8080) — it works with the network off.
